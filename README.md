KSRISax - Kohn Sham Radial Ion Sphere in JAX

Using Kohn-Sham Density Functional Theory (KS-DFT) to investigate ionization potential depression in warm dense matter. This is the repo for my codes and contributions to the project led by Dr. Aidan Crilly from the Department of Physics at Imperial College London.

Crilly's Github Repo for KSRISax: https://github.com/aidancrilly/KSRISax

Still a work in progress, currently working on optimization of the phase shift corrected DOS solvers since they are slow, and also working on integrating it with the SCF solver.
